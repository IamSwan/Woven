Woven UI kit

This page has two parts. Part 1, the target design, is what we want in game: new and reworked UI is built toward it. Part 2, the live place, is a read-only export of the UI that exists in Roblox Studio today, and stays the record of the place. Each live screen in Part 2 says whether the target keeps it, reworks it or has no board for it yet.

Status legend: Kept in target the live screen stays as it is (V1) · Reworked in target redesigned in Part 1, with links to the boards · No target yet no board in Part 1 · Live in use · Warder mode only in Guardian mode · Legacy dead or duplicate (the last three come from docs/client.md §5).

Part 1: Target design New screens not built yet; V1 screens kept as they are

This is what we build toward in game, drawn from the UI audit (2026-11-08). New and reworked UI follows these boards. Part 2 below is the live place, the record of what exists in Studio today; each live screen there says whether the target keeps it, reworks it or has no board for it yet.

Every image is the game's own art from docs/ui-kit/assets, and the fonts are the Roblox fonts in assets/fonts.css. Bracketed labels such as [Player] or [Form 1] are placeholders for data not known yet; numbers such as levels, kills and Marks are examples. Weave facts (Fireball: Fire, Fire, Air, 65 mana, range 60, 15 s ready window) come from the docs.

The top bar (V1 TopHUD), the minimap and the credits screen are the V1 screens, kept as they are. The boards are the file tools/ui-kit/target.html, which node tools/ui-kit/build.mjs inlines into this page: edit that file, not index.html. Tick "actual size" in the top bar to see the boards unscaled.
